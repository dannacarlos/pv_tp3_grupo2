# Plataforma de Gestión de Proyectos Educativos - TP N° 3

Evolución de la plataforma estática de "Gestión de Proyectos Educativos" hacia una aplicación web dinámica utilizando **React** y **Vite**. Este proyecto integra lógica modularizada mediante servicios y componentes funcionales interconectados a través de `props` y estados dinámicos en tiempo real (`useState`).

## Características Principales
* **Estructura Modular:** Fragmentación de la interfaz en componentes reutilizables (`Header`, `Nav`, `Footer`, `ProyectoCard` y `DetalleProyecto`).
* **Lógica Orientada a Servicios:** Gestión de datos centralizada en `proyectoService.js` mediante una función autoejecutable (IIFE).
* **Control de Estados y Props:** Comunicación eficiente entre componentes para el flujo de datos.
* **Interactividad Completa:** * Búsqueda y filtrado de proyectos en tiempo real.
  * Inspección de información extendida (Detalles, recursos y equipos de trabajo).
  * Formulario reactivo para la inserción de proyectos complejos.
  * Eliminación inmediata de elementos del tablero.
